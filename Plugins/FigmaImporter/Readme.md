# Pixso → Figma Importer

Dev-плагин Figma для пакетов, которые генерирует `Plugins/ExportNodes`.
Он создаёт нативные Figma-ноды, а не скриншот: фреймы, auto layout, текст, базовые
фигуры, заливки, обводки, эффекты, SVG-векторы и изображения. В основном режиме
screen собирается как самодостаточное visual snapshot-дерево без импорта component
definitions. Каждый Pixso instance получает semantic metadata. При включённой
опции `Собрать настоящие Figma-компоненты и инстансы` snapshot-фреймы
автоматически превращаются в нативные components/instances. Опция полной локальной
библиотеки остаётся отдельным экспериментальным режимом.

Опция `Собрать настоящие Figma-компоненты и инстансы` выполняет такой semantic
проход сразу после визуальной сборки. Snapshot-инстансы обрабатываются снизу вверх:
первое resolved-дерево каждой component/variant-сигнатуры становится локальным
`ComponentNode`, остальные вхождения заменяются его `InstanceNode`. Варианты с
одинаковым `definitionSetName` объединяются в `ComponentSetNode`. Это сохраняет
успешный визуальный импорт как исходную точку и не зависит от прямой совместимости
внутренних component definitions Pixso и Figma.

Обводки переносятся с покрасками и style binding, общей и посторонней
толщиной, align, cap, join, miter limit и dash pattern. Для разделителей в auto layout
`FILL` дополнительно переводится в `layoutGrow/layoutAlign`, чтобы линия не сжималась
до своей исходной минимальной ширины.

## Использование

1. В Pixso запустите `Portable Exporter` и включите `Точное содержимое инстансов`.
   Для тестирования структуры SVG и изображения можно выключить.
2. В Figma импортируйте `manifest.json` как development plugin и запустите его.
3. Выберите выгруженный JSON и нажмите `Импортировать`.

После импорта плагин добавляет корневой screen frame на текущую страницу и
нормализует его позицию относительно `0,0`. Каждой созданной ноде записывается
`pixsoPortableId` в plugin data — это основа для будущего incremental sync.

## Границы точности 1:1

Формат передаёт почти все необходимые данные. Нативно воспроизводятся обычные слои и
local components. Ограничения Figma API/движков остаются для видео, blend mode,
части сложной векторной геометрии без SVG, неизвестных шрифтов, remote library links,
prototype interaction и bindings Variables/Styles: importer сохраняет raw-значение и
пишет предупреждение. Поэтому «один в один» нужно подтверждать визуальным сравнением,
а не только успешным импортом.
