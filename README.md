# Pixso2Figma

Pixso2Figma is an independent project for transferring designs from Pixso-exported files into Figma.

This repository contains multiple generations of the project. The repository contains two builds of Pixso2Figma: **Rainbow** and **Alpha**. **Rainbow** is the current and actively maintained build, while **Alpha** is deprecated and kept for historical/reference purposes.

## Builds

### Rainbow — Current

Rainbow is the current and recommended build of Pixso2Figma.

It processes user-provided files exported from Pixso and transfers supported design data into Figma.

### Alpha — Deprecated

Alpha is the original, deprecated build of Pixso2Figma. It is no longer actively maintained and is provided as-is for historical/reference purposes.

Alpha remains available under the **MIT License** included with that build. Its existing MIT licensing is not changed by the licensing terms of Rainbow.

## Project Status

- **Rainbow** — current and maintained
- **Alpha** — deprecated / legacy

New development is focused on Rainbow.
